# 🚗 SMART RIDE AGGREGATION PLATFORM - Real-Time Comparison of OLA, UBER & RAPIDO

### 📌 Abstract
The rapid growth of Ola, Uber, and Rapido has enabled convenient transport, but also introduced dynamic and inconsistent fare pricing. At any given time, each platform displays a different fare for the same source and destination due to surge pricing and demand. This project introduces a multi-objective system integrated with Machine Learning price-prediction models. The system collects historical data, trains individual ML models for each service, and predicts real-time fares to recommend the cheapest and most optimal ride.

**Keywords:** Multi-objective optimization, Ride fare prediction, Machine Learning, Dynamic pricing, Cost minimization.

### 🎯 Problem Definition
Ride-hailing platforms often display significantly different fares for the same journey. Users have to manually compare prices across multiple apps, which is time-consuming and may lead to selecting a more expensive option. There is no integrated system that can simultaneously predict and compare fares.

### ✨ Objectives
- To design a unified platform that enables users to view and compare ride details from multiple services in one place.
- To build ML models that accurately predict ride fares based on pickup, drop, distance, and time.
- To assist users in selecting the most cost-effective ride option.
- To present clear, accurate, and transparent ride information to users.
- To enhance transparency in fare selection by providing unbiased, data-driven comparison.

### 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript, React
- **Backend:** Python (Flask / Django)
- **Machine Learning:** Python, Pandas, Scikit-Learn, Random Forest, Decision Tree
- **Database:** MySQL / CSV Dataset (ola_rides.csv)
- **Tools:** Git, GitHub, VS Code

### 📁 Scope of Project
- Integrates data from multiple ride-hailing services into a unified system.
- Continuously updates ride information for accurate real-time comparison.
- Retrieves and displays live ride details like fare, vehicle type, availability.
- Provides visualization of price trends and ride statistics.
- Implements ML models for continuous improvement of fare prediction.

### 🚀 How to Run
1. Clone the repo:
   `git clone https://github.com/sruthiandimalla/Ride-sharing-.git`
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python app.py`
4. Open browser and enter pickup & drop location to get fare predictions.
